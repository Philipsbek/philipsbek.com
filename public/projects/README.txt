Project images go here.

The portfolio cards currently use tasteful generated placeholder thumbnails
(no external images needed). When you have real screenshots:

1. Drop image files in this folder, e.g. /public/projects/my-store.jpg
2. Open src/data/site.js and, on the matching project, add an `image` field
   pointing to the file (and set `placeholder: false`).

Keep images optimized (ideally < 300 KB, 16:10 ratio, ~1200px wide).
